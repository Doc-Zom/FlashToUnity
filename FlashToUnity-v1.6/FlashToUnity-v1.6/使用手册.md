# FlashToUnity 使用手册

适用于 v1.6。可以先将 SWF 转成 Unity 动画，再替换美术或添加部件；只需要播放原动画时，完成导入即可。

## 1. 安装与升级

将发布包的 `FlashToUnity` 文件夹复制到工程 `Assets` 下，得到 `Assets/FlashToUnity/Editor` 和 `Assets/FlashToUnity/Runtime`。等待编译后，Tools 菜单出现两个入口：

- **Flash 动画导入 (SWF → Unity)**
- **Flash 角色制作（换装与部件绑定）**

已在 Unity 2022.3.20f1c1 验证，其他版本请先在独立工程检查。菜单未出现时，查看 Console 中的编译错误，也包括其他工程脚本的错误。

升级时更新同一个安装目录，不要同时保留两份插件；已有文件的 `.meta` 应保留。若曾安装带开发辅助功能的版本，可移除插件中的 `Editor/FlashBatch.cs` 及其 `.meta`，本发布版不再包含它。原创角色运行时依赖 Runtime 文件夹，不能在打包前删除它。

## 2. 第一次导入

1. 打开动画导入窗口，拖入一个或多个 `.swf`，也可以点击文件区域选择文件。
2. 使用默认输出目录 `Assets/FlashAnims`，或另设一个 Assets 下的专用目录。
3. 第一次检查建议关闭「整帧预渲染模式」，分段选择「不分割（整段一个片段）」。
4. 点击「开始导入」，等待生成完成，查看窗口下方日志。
5. 将生成的 Prefab 拖入场景，确保相机能看到角色，再进入 Play 模式。

每个 SWF 有独立输出子目录：

```text
Assets/FlashAnims/MyCharacter/
  Textures/                    部件图片
  Animations/                  AnimationClip 与 AnimatorController
  MyCharacter.prefab           可直接放入场景的角色
```

整帧预渲染使用 `Frames/` 保存逐帧图片，Prefab 名称带 `_prerendered`。

## 3. 导入设置

| 设置 | 含义与选择建议 |
| --- | --- |
| Pixels Per Unit | 每个 Unity 单位对应的像素数，默认 100；值越大，角色在场景中越小。 |
| 整帧预渲染模式 | 关闭时生成部件层级与变换动画；开启时每帧生成一张图片，以换图播放。需要换装或绑定时关闭。 |
| 子时间轴循环播放 | 控制 SWF 内嵌元件到末帧后循环或保持，不控制最终 Unity 动画片段的循环。 |
| 矢量超采样 | 范围 1～4，默认 2；提高矢量轮廓采样质量，也增加导入成本。 |
| 不压缩贴图 | 默认开启，减少压缩造成的颜色和边缘损失，代价是更多存储和显存。 |
| 贴图过滤 | Bilinear 适合平滑画面；Point 适合希望保留像素格的素材。 |

整帧预渲染同样受支持的 SWF 特性限制，不保证补全所有 Flash 特效，也难以独立修改头、手等部件。

### 动作分段

| 方式 | 用途 |
| --- | --- |
| 自动 | 优先按源文件帧标签，否则按内容变化尝试分段。 |
| 仅帧标签 | 源文件已标注动作起点。 |
| 自动分段 | 按内容变化检测，结果需要人工检查。 |
| 手动指定帧号 | 输入如 `29,79`，第 0 帧自动作为第一段起点。 |
| 不分割 | 保留完整主时间轴，适合检查整体转换效果。 |

「预览自动分段」只显示检测结果，不生成角色。帧号从 0 开始，分段起点属于新片段。分段用于层级模式，整帧预渲染输出完整片段。

要循环播放最终 Unity 动画，请设置生成 AnimationClip 的 **Loop Time**。复杂动作切换建议建立独立 AnimatorController，避免自定义状态被重新导入覆盖。

## 4. 创建可换装角色

1. 打开角色制作窗口。
2. 将层级模式生成的 **Prefab 资源**拖入「原动画 Prefab」，填写名称。
3. 点击「创建独立角色与换装配置」。

新角色与配置保存在 `Assets/FlashCharacters/角色名/`，场景中同时创建实例。角色的 `Motion` 子对象提供原动作，根节点的 `FlashCharacterRig` 应用换装配置。

后续选中场景角色，在组件里点击「打开角色制作窗口」，或在窗口点击「使用场景中选中的角色」。

## 5. 换图与造型调整

1. 将自制图片的 Texture Type 设置为 **Sprite (2D and UI)**，点击 Apply；多图 Sprite Sheet 应先切分。
2. 在窗口选择部件，通过「当前原图」确认目标。
3. 可以修改「自定义名称」方便识别，这不会改变动画绑定路径。
4. 将新 Sprite 拖入「替换图片」。
5. 调整「贴图位置」「贴图角度」「贴图比例」，配合动作预览检查。

**匹配原图尺寸**按原图宽高调整新图；两图宽高比不同可能拉伸。关闭后使用新 Sprite 的尺寸与 PPU，再手工调比例。图片有透明留白时，匹配的是整张矩形尺寸，不是可见轮廓。

**指定贴图绑定点**决定图片上的哪一点对齐动画连接处。左下角为 `(0,0)`，中心为 `(0.5,0.5)`，右上角为 `(1,1)`。例如头部从底部连接身体，可以把绑定点放在靠下的位置。

**逐张图片替换**用于同一部件随动画切换多张图。左边填写原 Sprite 名称，右边指定新图。匹配条目优先于统一替换；未匹配时使用统一替换或原图。原图名称应唯一，避免多个同名素材被视为同一项。

## 6. 造型比例与动作强度

- **贴图比例**改变造型大小，例如把头做大。
- **动作缩放强度**改变运动中的伸缩幅度：1 保留原动作，0 固定为绑定姿势，其他值增强或减弱变化。
- **动作位移强度／动作旋转强度**分别控制相对绑定姿势的移动和旋转变化。

绑定姿势来自创建角色时捕获的原始姿势；刷新列表会保留已有部件的绑定姿势。复杂剪切或镜像下，缩放参数控制的是二维矩阵分解后的形变，不等同于骨骼长度，应检查整个动作。

「跟随动作部件」可以让现有部件改用另一部件的运动，再用贴图参数修正造型。工具不会自动识别头、手、脚，也不会自动生成新关节动作。

## 7. 添加与绑定新部件

1. 点击「添加新部件（图片或 Prefab）」。
2. 输入名称，指定 Sprite 或 **Project 中的 Prefab 资源**。普通场景对象要先保存为 Prefab。
3. 在「绑定到」选择原部件，或另一个新增部件。
4. 初次检查先把位置设为 `(0,0)`、角度设为 0、比例设为 `(1,1)`，确认显示后再调整。

例如把新头绑定到原头的动作，再把帽子绑定到新头。支持多级绑定，但不能互相循环；无效或丢失目标会显示警告。

| 选项 | 开启后的效果 |
| --- | --- |
| 跟随旋转 | 继承目标旋转。 |
| 跟随缩放 | 继承目标伸缩和形变。 |
| 跟随显隐 | 目标在当前帧隐藏时，附件也隐藏。 |
| 跟随颜色 | 把目标颜色乘到附件基础颜色上。 |
| 跟随显示层级 | 使用目标顺序加层级偏移；正值通常显示在目标前方。 |

关闭显示层级跟随时，使用所填的 Sorting Layer 和显示顺序，并保留 Prefab 内 Sprite 的相对顺序。这里控制的是 SpriteRenderer，含 MeshRenderer、UI 等复杂结构的 Prefab 不保证获得相同的颜色、显隐或排序行为。

没有自身图片的动画容器也可绑定。对于自身透明、内部部件负责显示的容器，会参考内部部件的可见状态；容器颜色不一定适合作为附件颜色来源，需要独立颜色时关闭颜色跟随。

Prefab 可以携带自己的 Animator。编辑窗口只采样原角色动作，附件 Animator 在运行模式播放。附件自行控制颜色时应关闭颜色跟随；显示顺序由绑定配置控制。Prefab 和图片同时配置时优先使用 Prefab。

## 8. 预览、保存与独立变种

选择动作后播放或拖动时间滑块。「暂停」保留当前姿势，「还原初始姿势」退出预览并恢复状态。若其他动画窗口正在预览，先结束那里的预览。资源中的 Prefab 可通过「实例化以预览」放入场景。

完成后点击「保存配置」。场景需另行保存。修改根组件上的配置引用后，需要按自己的工作流程应用到 Prefab，或另存为新 Prefab。

多个角色引用同一配置时，修改会影响全部实例。要制作独立变种，点击「复制为独立配置」，再将实例保存为新角色 Prefab。仅复制 Prefab 不会让配置自动独立。

运行时生成的显示对象是临时对象，无需手工保存或编辑；禁用角色组件会恢复原始部件显示。

## 9. 重新导入

同名资源在同路径重新导入时原位更新并保留 GUID，目录内其他文件不会整批删除。生成的动画曲线和控制器状态会更新，自定义动作、状态机和角色应放在独立目录。旧的未使用生成文件不会自动清理。

改变 SWF 名称、分段名称或源层级可能改变资源路径和绑定目标。之后请刷新部件列表、检查警告并重新指定变化的目标，工具不会自动猜测新旧部件的对应关系。

## 10. 常见问题

**新增部件看不到？**  
检查是否指定图片或 Prefab、目标是否有效、有无循环绑定。目标可能在后面的帧才出现，可播放到对应帧，或取消「跟随显隐」。再将位置暂设为 `(0,0)`、比例设为 `(1,1)`，检查透明度、显示顺序和相机范围。

**图片或对象拖不进栏位？**  
图片栏接受 Sprite，需先完成导入设置；Prefab 栏接受资源，不能直接保存场景对象引用。

**播放后手工位置被恢复？**  
原动画节点受 Animator 驱动，请通过角色制作窗口调整造型和动作强度，而非直接修改 Motion 内的节点。

**结果缺部件或与源文件不同？**  
查看日志，再检查源文件是否包含未支持的 JPEG、文本、变形形状、滤镜、混合模式、复杂遮罩或 ActionScript。切换输出模式不保证补全这些效果。反馈时附 Unity 版本、设置、日志及获准分享的最小 SWF。
